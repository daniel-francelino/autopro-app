# Lean build

- Define observable acceptance and non-goals.
- Reuse existing interfaces and ownership boundaries.
- Implement the smallest coherent vertical slice; do not hide invariant problems with local hacks.
- Avoid speculative config, abstractions, providers, dependencies and polish.
- Run focused proof and stop when acceptance and risk gates pass.
